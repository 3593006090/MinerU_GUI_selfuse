3 分钟上手本地 MinerU

这份教程带你从「启动」到「解析出第一篇文档」，每一步都可以直接试。

文件不出本机 RTX 3070 GPU 加速 PDF / 图片 / Office Markdown 输出

1启动服务（已安装，只需知道怎么开）

这个操作台由两部分组成：后端服务（端口 7861）+ 页面。双击下面这个脚本即可启动：

E:\MinerU\start-console.cmd

启动后浏览器访问 http://127.0.0.1:7861。想用命令行解析，也可以直接运行：

E:\MinerU\bin\mineru-kit.cmd parse D:\docs\paper.pdf -o D:\out\paper.md --tier standard
原版 Gradio WebUI（端口 7860，双击 start-webui.cmd）也保留着，两者可以同时使用。
关闭服务：双击 stop-console.cmd（操作台）或 stop-webui.cmd（原版 WebUI）即可，脚本会把占端口的子进程一起清理干净。

2三步解析一篇文档

① 上传：在工作台左侧点上传框，或把文件拖进去（支持 PDF、图片、Word、PPT、Excel、HTML 等）。

② 选档位：默认 Standard 即可，它会同时用小模型和 VLM，版面、公式、表格效果最好。

③ 开始解析：点按钮后可以看到实时阶段和日志。单页 A4 大约 8 秒；首次使用需要加载模型，会多几秒。

完成后右侧会显示 Markdown 预览，可切换「Markdown 源码」，并可下载 .md 或整个结果 ZIP。

Office 文档（docx/pptx/xlsx 等）会自动走 flash 快速通道，这是 MinerU 的固定行为，不是出错。

3选对档位，速度与质量兼得

Flash

只提取 PDF 原生文本层，不跑模型

约 1 秒/页

Basic

小模型 OCR / 版面 / 表格，不需要 VLM

约 3 秒/页

Standard

小模型 + VLM，复杂版面、公式、表格质量最好

约 8 秒/页 · 推荐

Advanced

更多推理计算，追求极致质量

约 15 秒/页
Standard：适合论文、报告、教材等复杂版式。电子版 PDF 也可以先试 Flash 快速预览。

5命令行与 API 调用

命令行解析（适合批量处理）：

REM 单个文件 → 指定 Markdown 输出 E:\MinerU\bin\mineru-kit.cmd parse D:\in\paper.pdf -o D:\out\paper.md --tier standard REM 整个目录 → 打包输出 E:\MinerU\bin\mineru-kit.cmd parse D:\in -o D:\out --format zip

HTTP 接口（适合程序集成，本操作台自己也用它）：

# 1. 上传文件 curl -F "file=@D:\in\paper.pdf" http://127.0.0.1:7861/api/upload # 2. 创建解析任务（用上一步返回的 file_id） curl -F "file_id=返回的file_id" -F "tier=standard" http://127.0.0.1:7861/api/tasks # 3. 轮询结果（返回 markdown 字段） curl http://127.0.0.1:7861/api/tasks/任务ID

Python SDK（虚拟环境内）：

from mineru import parse result = parse(r"D:\in\paper.pdf", tier="standard") print(result.markdown)

7常见问题

解析很慢 / 卡在「加载模型」？

每次命令行解析都会重新加载模型，第一次通常 5~10 秒。8GB 显存下建议一次只跑一个任务；同时开游戏或视频渲染可能显存不足。

为什么上传 Word/PPT 后档位变成 flash？

MinerU 4.0 中 Office、HTML、EPUB 等格式固定走本地 flash 解析（原生结构转换），只有 PDF 和图片支持 basic/standard/advanced 档位。

扫描件 PDF 效果不好？

扫描件请用 Standard 档位（VLM 会处理），不要用 Flash——Flash 只读文本层，扫描件没有文本层。如果扫描质量很差，解析前先保证图片清晰、倾斜校正。

结果里的图片为什么是 base64？

MinerU 4.0 的 Markdown 会把图片内嵌为 data URI，好处是单个 .md 文件即可完整预览和分享。需要单独图片文件时下载 ZIP 即可。

能离线使用吗？

可以。模型已在 E:\MinerU\models 下载校验完毕，解析全程本地推理，不联网、不上传。
